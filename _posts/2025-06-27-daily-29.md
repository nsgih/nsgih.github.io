### 依附理论(John Bowlby, 1980)

人类从婴儿时期起就会与照料者形成“依附”，成年后也将这种模式带入亲密关系中。

| 类型                   | 概述                         | 关键词             |
| ---------------------- | ---------------------------- | ------------------ |
| 安全型（Secure）       | 信任亲密关系、情绪稳定       | 互信、独立、温和   |
| 焦虑型（Anxious）      | 害怕被抛弃、强烈寻求回应     | 紧张、粘人、易情绪 |
| 回避型（Avoidant）     | 害怕失控、抗拒依赖           | 疏离、自主过度     |
| 混乱型（Disorganized） | 渴望又恐惧亲密（多创伤背景） | 矛盾、剧烈情绪波动 |

```
安全：信任 情绪调节 空间自由 表达需求 看待误解
焦虑：怕被忽视 延迟即焦虑、连发 情绪波动容易爆发 需要安慰和确认
回避：害怕暴露感情/被依赖 压力冷处理 拒绝我们/倾向你|我

🔍 四、自查建议（你可以试着回答自己）
- 当对方不回复我时，我更倾向于：（冷静/焦虑/爆发/关掉消息）？
- 我觉得在关系中，最不能接受的是？（被忽视/被控制/没有回应）
- 我更容易说出“我需要你”还是“我一个人就好”？
- 我是否会用沉默或疏远来惩罚对方？
- 当对方对我冷淡时，我会主动解释、观察对方、试图惩罚对方还是直接自责？
```

```yaml
连发责问： 在短时间内连续发送大量质问或控诉消息，让对方感到情绪压力或无法回应。
情绪绑架：把自己的情绪（失望、生气）变成对方必须负责的东西。“你不回我 → 就说明你不在乎我 → 就是你不对。”
情绪升级：从失望→生气→愤怒→攻击性，逐级上升，话语越来越伤人。
否定人格：将问题扩大为对方“整个人”的否定，彻底推翻曾经的信任。
```

```yaml
🧊 方法一：降温式表达
替代“你是不是根本不在乎”：“我有点不确定你是不是没看到消息，但我其实是挺期待你回的。”
替代“我删人了”：“我其实挺难受的，但我不想吵，我希望我们能好好说清楚。”

📬 方法二：留空间但不退让
不要一口气连发十条，让对方无从应对；
可以发两三条之后就说：“我等等你有空再回我”。
```

### HSP

```yaml
📌 本质问题：
✔️你不是怕冲突，而是：
你希望一次沟通就能解决问题，而不是进入“反复沟通、反复提醒”的不对等互动。
✔️你心里其实有一个隐形标准是：
“我尊重你，所以我为你考虑；如果你也尊重我，你应该自然意识到我的感受。”
而现实是：大多数人并没有那么敏锐，也不会因为一次提醒就形成习惯改变。
✔️所以你在这个地方受了两层伤：
行为没改变 → 表面上你觉得是“不守规矩”；
你被忽视了 → 本质上你觉得是“我的情绪不被放在眼里”。

✔️ 1. 建立“边界-反馈”机制
你可以这样表达：
“我之前跟你说过一次关于声音的事，你可能一时没注意，但我对声音特别敏感，这不是偶尔，是常态。你愿意一起找个解决方式吗？”
✔️ 2. 承认你的“低容忍阈值”
不是羞耻。你需要的不是“让别人都顺你”，而是找到能跟你协同的人，或者协商机制。
✔️ 3. 改掉“沉默是反制”的思维
沉默只是让你感觉你赢了，但其实你失去了反馈回路、磨损了关系质量，而且自己越想越痛。

“我是一个对环境和情绪都非常敏感的人，我对人际间的默契有比较高的期待，一旦被忽略，会很难再主动沟通。但我正在学习用边界感清晰、非爆炸式的方式表达我自己。”
```
