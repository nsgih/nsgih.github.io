#### spring

```yaml
controller-service-repository-model:
    # 控制器 业务 数据访问持久 实体数据模型 
    - controller: 对接前端的http-request，调用service而不处理具体业务
    - service: 负责具体业务，业务逻辑集中在service；如数据校验、事务控制、调用repository
    - repository: 负责交互db；只处理数据crud不负责业务逻辑
    - model: 定义db结构和数据对象，通常用JPA注解标注
    - ie: 
        - CollectionController # controller
        - CollectionService # service
        - ColletctionFileRepository # repository
        - CollectionFile # model
```
