#### spring

```yaml
controller-service-repository-model:
    # 控制器 业务 数据访问持久 实体数据模型 
    - controller: 对接前端的http-request，调用service而不处理具体业务
    - service: 负责具体业务，业务逻辑集中在service；如数据校验、事务控制、调用repository
    - repository: 负责交互db；只处理数据crud不负责业务逻辑
    - model: 定义db结构和数据对象，通常用JPA注解标注
    - ie: 
        - CollectionController # controller
        - CollectionService # service
        - ColletctionFileRepository # repository
        - CollectionFile # model
```

### 0830

#### 风尘杂谈

依旧是之前那件事，实在是焦虑的没办法了，无从下手，索性看看彼岸风尘的世界。这一看倒是有些黑暗：风尘女子中，有来自耳熟能详大学的，有索性放自己裸露照的，有自称空姐可以额外伴飞的。介绍上写了落落长的风尘文，价格挡位倒是很干脆：3k, 5k; 10k外围。问了AI，外围似乎有双重含义：一指非相关方的外围人士，例如演艺圈场合中负责陪酒、陪睡、陪玩的服务人员；二指风尘产业落在灰色地带，游离在法律外围。但无论如何，当看到袒胸露乳以宣传自己者，实在是看不下去。

我选择花钱找陪玩。我将这种行为称之为“小风尘”。找王者荣耀陪玩的价位大概落在6~10左右/局，我采用的方式是每局换一个人————惶恐倘若以这种方式认识而熟络，会被瞧不起似的。当然，我都是找声音好听的人，毕竟花了钱，难免思索一番陪玩框架下自己的需求，例如：声音好听，能聊的开，赚钱执念不深云云。

第一个人是s，安徽某大学，烹饪专业，大二，有很重的学生感。第二个人是q，是个审计，好像也是安徽合肥人，感觉是常年带小孩的亚子，听上去是自信、可爱、不过分做作。第三个人是i，杭州人，总会用抛出自夸内容的方式聊天，逞强的样子让我想到vegas。第四个人是z，心理咨询，30min/30cny。说了一些很有意思的观点，尤其能跟上我的语速和思路(对于陌生人之间，以及在我特别喜欢省略宾语的情况下顺畅快速交流，实属非常不易)，简直是失散的旧友啊！总之啊总之，大致花了90，新鲜感散去后就有些疲惫。恰好q主动发消息给我，便把剩下的钱都散在她身上，又聊聊我这两晚都做了什么，加了微信，说好有空再一起玩开黑。

不过很快我就有些汗流浃背：我似乎是自来熟过分啦。二是，如果我私下可以找她打游戏，颇有白嫖的嫌疑。想到这里我就有些不自在，感叹这风尘路上认识的人，交友考量的因素是真多。那晚后，q回消息也渐渐相隔几个小时，难以捉摸是礼貌回复，还是有交友意愿。想想，我俩似乎也没开黑之外的共同话题，于是啊于是，综合以上三个原因，最终放弃交友，只在平台下单找q。这交友执念上的一来一回，回消息时脑中总是要折腾一段，久而久之又凭空生出了新的焦虑，我真是笨蛋呐！

古时立下誓言要娶风尘女子的书生大概就是这种感觉，轻言细语中似乎有些真诚，不过纯赚钱的立场也解释得通。夸你呐，又像是要赚你钱，又像是鼓励朋友；声音好听呐，又会想朋友之间态度这么好，实在是奇怪。写到这我都觉得自己在瞎折腾，但总之从风尘路上，小散银两，游历一番回归了现实。

在我的印象里，吉普赛人总是要戴着面纱，双手放在水晶球上给出占卜。占卜的结果往往都不是什么好消息，宏大却精准，老早告诫你一切早有定数。和z的心理咨询就是这样的情况，有机会再写关于z的那两次心理咨询。
