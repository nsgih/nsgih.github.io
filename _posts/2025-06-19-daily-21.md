#### 欧拉

![alt text](/assets/2025-06/500px-Leonhard_Euler_2.jpg){: w="200" h="200"}_莱昂哈德·欧拉（德语：Leonhard Euler，1707年4月15日—1783年9月18日）_

```yaml
- 伯努利家族 伏尔泰 欧拉
- 严密性: （在数学中）指涉不依赖直觉、图像、例子或语义模糊的说法，而是完全建立在逻辑系统和公理基础上的推理方式。
- 康托: 集合论的双射细化"无限小"，用基数指涉可数无穷、不可数无穷
    - N Z 等势
    - N Q 等势
    - R 比 N 更大
```

| 领域 | 原来靠…        | 严密化后由谁完成       |
| ---- | -------------- | ---------------------- |
| 几何 | 图形直觉       | 欧几里得 → 希尔伯特    |
| 实数 | 数轴经验       | 戴德金、康托           |
| 极限 | 趋近、越来越小 | Cauchy、Weierstrass    |
| 积分 | 面积直观       | 黎曼 → 勒贝格          |
| 复数 | 看起来没问题   | 高斯、阿贝尔系统化解释 |
| 无限 | 玄学           | 康托用集合论严格定义   |
